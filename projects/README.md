## 장비실 대여 시스템

성균관대학교 영상학과의 장비·시설 대여를 관리하는 웹 서비스입니다.

- **개발**: 2026.01–04, 1인 외주 개발
- **담당**: 서비스 개발 및 운영
- **현재 상태**: 서비스 중 · 코드 비공개
- **기술**: TypeScript, React, PostgreSQL

학생은 필요한 장비와 시설을 신청하고, 관리자는 신청을 확인해 승인한 뒤 수령과 반납을 처리합니다. 신청이 겹치는 경우의 조정, 일부 장비만 반납하거나 다른 학생에게 양도하는 경우도 다룹니다.

장비를 예약하는 화면뿐 아니라, 대여가 시작된 이후 장비실에서 처리하는 업무까지 구현한 프로젝트입니다.

- **현재 상태**: 개발 중 · 코드 비공개

- **현재 상태**: 개발 중 · 코드 비공개

현재는 가구의 부품과 배치를 3D로 검토하는 화면을 구현하고 있습니다. 회사와 제품을 소개하는 홈페이지, 실제 가격을 산출하는 견적 기능은 추가할 예정입니다.

## 1KM

릴스 형식의 영상을 탐색하고, 열어 본 영상 수가 종이의 길이로 출력되는 체험형 인터랙티브 아트입니다.

- **작업**: 관람 화면과 출력 프로그램 개발
- **구성**: 웹 관람 화면, Python 출력 프로그램
- **기술**: TypeScript, React, Python
- **코드**: 비공개

화면에서 영상을 둘러본 기록이 출력물로 이어집니다. 관람 화면과 출력 프로그램을 연결하고, 출력 중 연결이 끊기는 상황의 처리도 다뤘습니다.

같은 인터랙티브 아트 작업으로는 [비밀의 못](https://github.com/SungKong00/the-secret-pond-sound-system)이 있습니다. 비밀의 못은 목소리를 녹음하고 쌓아 함께 재생하는 작업으로, 2026년 5월 실제 전시에 사용했습니다.
