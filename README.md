## 🚀 요즘 가장 열심히 만든 것들

### ⛷️ [SSING Server](https://github.com/TEAM-SSING/SSING-SERVER)

스키장·일정·실력·인원 조건으로 강습생과 강사를 연결하는 서비스입니다.
서버 리드로 참여해 매칭, 인증, 알림과 운영 인프라를 함께 만들었습니다.

`Java 21` `Spring Boot` `MySQL` `WebSocket` `AWS`

### 🏛️ [University Group Management](https://github.com/SungKong00/univ_group_management)

학과·동아리·학회의 소통, 권한, 일정과 공간 예약을 한곳에 모은 대학 워크스페이스입니다.
기획부터 Flutter 화면, Kotlin 백엔드까지 혼자 만들었고 테스트도 455개 이상 작성했습니다.

`Kotlin` `Spring Boot` `Flutter` `PostgreSQL` `JUnit`

### 🎛️ [Harness Maestro](https://github.com/SungKong00/harness-maestro)

AI 에이전트가 필요한 문서와 검토 관점만 골라 안전하게 구현·검증하도록 돕는 개발 도구입니다.
AI에게 일을 잘 맡기려면 어떤 구조와 검증이 필요한지 직접 실험하며 만들고 있습니다.

`Python` `CLI` `Agent workflows` `Evaluation`
